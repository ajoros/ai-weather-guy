# AI-Weather-Guy

A WeatherNext 3 forecast viewer for North America and the North Pacific.

**Live:** [ajoros.github.io/ai-weather-guy](https://ajoros.github.io/ai-weather-guy/)

WeatherNext 3 is Google DeepMind research. This page is experimental. It is not an official forecast, watch, or warning, and it is not NWS. Do not use it for life-and-property decisions.

Real-time WeatherNext fields follow Google’s experimental data terms.
